# 幸运选号

一个使用 Vue 3、TypeScript 和 Reicon 构建的双色球 / 超级大乐透随机选号工具。

## 功能

- 双色球：6 个红球（1–33）+ 1 个蓝球（1–16）
- 超级大乐透：5 个前区号码（1–35）+ 2 个后区号码（1–12）
- 支持一次生成 1、3 或 5 注
- 复制当前结果和历史结果
- 会话内保留最近 10 批记录
- 适配桌面端和移动端

## 本地开发

```bash
npm install
npm run dev
```

## 验证与构建

```bash
npm test
npm run typecheck
npm run build
```
